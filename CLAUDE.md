# AstronomicalData

Allen Downey's "Astronomical Data in Python": seven notebooks that replicate part of Price-Whelan and Bonaca (2018) on the GD-1 stellar stream, using Gaia DR2 and Pan-STARRS queries (astroquery), Astropy, gala, and pandas. Developed with The Carpentries and the Astronomy Curriculum Development Committee; first given as the Carpentries test drive, online, November 16–20, 2020.

**Status:** self-study material. The maintained version is the Data Carpentry lesson ([site](https://datacarpentry.github.io/astronomy-python/), [source](https://github.com/datacarpentry/astronomy-python)). When something breaks here, check whether the lesson already fixed it and follow its fix; note differences on the board.

**Guide for the 2026 refresh:** the "Refresh checklist" in `~/GreenTeaPress/plans/workshops.md` (self-study variant). Progress goes on `PROJECT_BOARD.md` (Task 1) and in GreenTeaPress Task 24.

## Which notebooks are the workshop

- `soln/01_query.ipynb` … `soln/07_plot.ipynb` are the sources (solutions).
- `01_query.ipynb` … `07_plot.ipynb` at the root are the student versions, generated by `build.sh` (copies `soln/0*.ipynb`, runs `remove_soln.py`). Edit `soln/`, then regenerate; don't edit the root copies by hand.
- `test_setup.ipynb`: pre-workshop setup check.
- `data/`: files the notebooks download from GitHub (`gd1_results.fits`, `gd1_data.hdf`, `gd1_isochrone.hdf5`, the MIST isochrone). Outside links use these paths; don't move or rename them.
- Notebooks 01, 02, 04, 05 query the Gaia archive; 03, 06, 07 read saved files.

## Testing

Environment: `mamba env create -f environment.yml` (name `AstronomicalData`). Run the solutions top to bottom:

```
pytest --nbmake soln/0*.ipynb
```

Gaia queries are replayed from `tests/gaia_cache` when `IPYTHONDIR` points to `tests/ipython`, so tests don't depend on the Gaia service (CI does this; see `tests/gaia_replay.py`):

```
IPYTHONDIR=$PWD/tests/ipython pytest --nbmake soln/0*.ipynb
```

If a notebook's query changes, record again with `GAIA_REPLAY=record` (makes the real queries). The student versions don't run top to bottom (their blanks feed later cells), so they aren't tested. The target environment is Google Colab's Python (3.13) and libraries.

## Conventions

- Don't change the substance of the text; list content questions under "Content issues" on the board for Allen to decide.

- Branch is `main`.
